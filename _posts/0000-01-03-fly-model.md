A connectome says *who talks to whom*. To make it move, every neuron becomes a **leaky integrate-and-fire** unit, the recipe Shiu et al. used on the FlyWire brain (*Nature*, 2024):

| parameter | value |
|---|---|
| rest / reset | −52 mV |
| threshold | −45 mV |
| membrane time constant | 20 ms |
| refractory period | 2.2 ms |
| synaptic time constant | 5 ms |
| weight per synapse | 0.275 mV, signed by transmitter |

Sugar on the leg → feeding interneurons → proboscis motor neuron **MN9**. Bitter in the mix → inhibitory interneurons silence it.
